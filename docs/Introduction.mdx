# Glow UI

Code version of the Glow Design System.

- **Figma original** is the source of truth. Code mirrors it; the Figma file is never changed by this repo.
- **Registry**: components are copied into projects with the shadcn CLI and belong to the project after that.
- **Each story** carries Figma metadata (`parameters.design` and `parameters.glow.figma`) — the mapping between Figma and code.

> Scaffold stage: the theme and the Button are placeholders until the Figma audit and token export.
